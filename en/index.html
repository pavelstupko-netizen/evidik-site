How it works

Browser

The program opens in a browser on Windows, macOS and Linux. Nothing to install.

Server in Serbia

We host company databases in a Serbian data centre. We are choosing the data centre for the pilot now.

One database per company

The accountant works in the company's own database. Other companies' data stays hidden.

Backups and rollback

The service keeps database copies. You can roll back a mistake by one day.

It runs on the open ERPNext platform on Linux. The platform is not under sanctions, and its source code is open.
